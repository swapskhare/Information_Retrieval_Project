# Information Retrieval Chatbot

This project focuses on developing an **end-to-end Information Retrieval (IR) chatbot** that combines data scraping, indexing, query processing, and summarization. The chatbot supports casual conversations using BlenderBot and provides accurate, concise answers to topic-specific queries with summaries generated by BART.

## Features

### 1. Wikipedia Scraper
- Scrapes and indexes a dataset of **50,000 unique documents** across 10 topics:
  - **Topics**: Health, Technology, Environment, Economy, Entertainment, Sports, Politics, Education, Travel, and Food.
  - Ensures at least **5,000 unique documents** per topic.

### 2. Chit-Chat Component
- Implements **BlenderBot** for engaging and natural conversations.
- Handles casual user interactions with dynamic, AI-driven responses.
- Removes the need for rule-based logic, enhancing user experience.

### 3. Topic Classification
- Automatically classifies user queries into one of the predefined topics.
- Limits the scope of information retrieval and summarization to the relevant topic.
- Supports multi-topic conversations for advanced use cases.

### 4. Q/A System with Summarization
- Retrieves the **top-k relevant documents** for user queries using advanced search techniques.
- Uses **BART**, a state-of-the-art summarization model, to generate concise and coherent summaries of retrieved information.

### 5. Exception Handling
- Prevents crashes and gracefully handles invalid or ambiguous queries.
- Ensures robust and uninterrupted chatbot performance.

### 6. Visualization and Analytics
- Provides detailed analysis of chatbot performance:
  - Topic-wise engagement and error tracking.
  - Query reformulation and grouping insights.
- Includes dashboards for interaction diversity and topic-specific analytics.

### 7. User Interface
- A web-based application hosted on **Google Cloud Platform (GCP)** for real-time user interactions.
- Designed for intuitive navigation and engaging user experience.

## Technical Stack
- **Chit-Chat Model**: BlenderBot for conversational AI.
- **Summarization Model**: BART for generating precise, context-aware summaries.
- **Backend**: Python-based scraping, indexing, and query handling.
- **Frontend**: Web interface for seamless user interaction.
- **Hosting**: Fully deployed on GCP for public accessibility.

## Web Application
   - Fully hosted on **Google Cloud Platform (GCP)**.
   - Accessible via a live URL.
