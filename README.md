This project is an end-to-end Information Retrieval (IR) chatbot designed as a comprehensive application to integrate knowledge from indexing, crawling, and retrieval systems. The chatbot allows users to interact in two primary modes: casual chit-chat and answering topic-specific queries by retrieving information from Wikipedia.

Key Features:
Wiki Scraper: Scrapes and indexes at least 50,000 unique documents from Wikipedia across topics such as Health, Technology, Environment, and more.
Chit-Chat Model: Implements an AI-based conversational component using pre-trained language models like DialoGPT or BlenderBot.
Topic Classification: Automatically classifies user queries into predefined topics to streamline relevant information retrieval.
Q/A System: Retrieves top-k relevant documents based on user queries and generates coherent summaries using generative models.
Exception Handling: Ensures robustness against invalid queries or failures.
Visualization: Provides a web-based UI with detailed chat analytics, error tracking, and topic-specific insights.
Deployment: Fully hosted as a web application on GCP for live interaction.
